Mint Pilot is a Rust-based CLI for automating and scheduling OpenSea mint transactions. It supports single-wallet minting, self-funded multi-wallet workflows, and an experimental EIP-7702 sponsored execution mode. The system handles OpenSea collection metadata and mint-stage discovery, wallet eligibility, calldata validation, EIP-1559 transaction handling, replacement transactions, receipt polling, wallet funding and withdrawal, and optional Telegram notifications. It also includes read-only calldata inspection so mint operations can be validated before signing or broadcasting.
